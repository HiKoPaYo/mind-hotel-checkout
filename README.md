## 📖 1. 프로젝트 개요 & 철학

이 앱은 중학생(1~3학년)의 건강한 정서 조절과 학교 위클래스(Wee Class) 상담을 돕기 위해 개발된 인터랙티브 심리 웹 게임입니다.  
내러티브 상담(Narrative Therapy)의 핵심 기법인 **‘문제의 외재화(Externalization)’**와 **‘의인화(Personification)’**를 게임 메커니즘으로 구현하였습니다.

- **핵심 컨셉**: 마음 호텔의 지배인(나)이 찾아온 불청객(문제 캐릭터)을 맞이하고, 시원하고 재미있는 9가지 인터랙티브 활동으로 기분 좋게 체크아웃시킨 후 원래의 평온한 호텔 룸(일상)을 되찾습니다.
- **심리적 효능**: 점수나 순위 경쟁 없이, 감정을 억누르지 않고 문제와 나 자신을 분리하여 '문제를 다룰 수 있다'는 통제감과 자기효능감을 경험하도록 설계되었습니다.

## 🎮 2. 앱 진행 단계 (6단계 파이프라인)

### STEP 1. 시작 화면 (호텔 체크인 로비)
- 메인 타이틀: **불청객의 체크아웃**
- 슬로건: *"내 마음속 불청객, 이제 체크아웃할 시간입니다."*
- 지배인 등록: 학년, 반, 지배인 이름(닉네임) 입력 및 위클래스 상담실 연동

### STEP 2. 나의 불청객 만들기 (문제 선택 & 캐릭터 커스터마이징)
- 12가지 주요 고민 영역 (시험 불안, 친구 관계, 외모 고민, 성적 스트레스, 부모님 갈등, 선생님 갈등, 미래 걱정, 비교하는 마음, 외로움, 분노, 무기력, 직접 입력)
- 불청객 이름 짓기 (예: 시험 괴물, 눈치 대장, 걱정 먹구름 등)
- 5가지 체형(먹구름, 슬라임, 털복숭이, 도깨비, 뾰족가시), 7가지 색상, 눈/입 표정, 덩치 크기 실시간 프리뷰

### STEP 3. 불청객과 상호작용하기 (마음 룸 & 심리적 거리두기)
- *"너 왔구나? 하지만 여긴 내 마음이야. 내가 주인이란다."*
- 캐릭터 콕콕 찔러보기(말랑 젤리 반응, 당황 대사, 뿅 효과음)
- 지배인(나)의 당당한 태도 대사 카드 선택
- 사전 스트레스 지수(1~10점) 측정

### STEP 4. 9가지 스트레스 해소 게임 (체크아웃 배웅 미션)
모든 게임은 실제 마우스 드래그 및 스마트폰/태블릿 터치 조작으로 동작합니다.

1. ⚾ **야구 홈런 게임**: 타이밍을 맞춰 배트 스윙! 타격 진동과 함께 장외 홈런(비거리 미터 측정 및 관중 환호)
2. ⚽ **축구 골인 게임**: 캐릭터 공을 뒤로 당겨 슬링샷 슛! 수비수를 피해 골망을 가르고 저 멀리 날아감
3. 👄 **와작와작 씹어버리기**: 커다란 귀여운 입 속으로 캐릭터를 드래그! 냠냠 씹어 달콤한 별사탕과 하트 조각으로 정화
4. 🎈 **펑! 터뜨리기**: 공기 펌프를 연타하여 풍선처럼 부풀린 후, 펑! 터지며 다채로운 콘페티 폭발
5. ✂️ **분쇄기 게임**: 분쇄기 투입구로 캐릭터를 넣으면 톱니바퀴가 돌아가며 알록달록 무지개 종이 리본으로 샤라락 분쇄
6. 🧹 **초강력 진공청소기**: 청소기 헤드를 손가락으로 조종하여 화면 곳곳을 돌아다니는 불청객들을 먼지통 속으로 쏙 흡입
7. 💧 **시원한 물풍선 던지기**: 화면을 탭하여 물풍선을 던져 어둡고 무거운 마음을 시원하게 씻어냄
8. ❄️ **꽁꽁 얼리고 깨뜨리기**: 급속 냉각 빔으로 얼린 후, 톡 쳐서 쨍그랑 맑은 얼음 조각으로 부서뜨리기
9. 🌪️ **바람으로 멀리 날려보내기**: 대형 선풍기 풍속을 MAX로 올려 봄바람에 실어 저 푸른 하늘 너머로 배웅

### STEP 5. 마음 되찾기 (감정 회고 & 3대 질문)
- 감정 선택: 조금 가벼워졌어요 / 재미있었어요 / 여전히 속상해요 / 아직 걱정돼요 / 잘 모르겠어요 (모든 감정을 있는 그대로 존중)
- 지배인의 3가지 질문:
  1. 불청객이 다시 찾아온다면 어떻게 해볼까요?
  2. 지금 나에게 가장 필요한 것은 무엇인가요?
  3. 지배인(나 자신)에게 해주고 싶은 말은 무엇인가요?
- 사후 스트레스 지수(1~10점) 측정 및 스트레스 감소 확인
- *"불청객이 다시 찾아와도 괜찮아요. 나는 나만의 방법으로 문제를 다룰 수 있으니까요."*

### STEP 6. 룸 상태 점검 & 공식 인증서 발급
- 깨끗하고 햇살 가득한 평온한 룸 컨디션 회복 (100% 정상 회복)
- **공식 체크아웃 인증서(영수증 카드)** 발급 및 PNG 이미지 다운로드 기능
- 백엔드 서버(REST API) 자동 저장 완료
- [처음부터 다시 시작하기] 지원

## 🛠️ 4. 기술 스택

- **프론트엔드**: React 19, Vite, TailwindCSS v4, Lucide Icons, Canvas Confetti, HTML2Canvas
- **오디오 엔진**: Web Audio API 내장 신디사이저 (외부 오디오 파일 없이 무지연 브라우저 네이티브 사운드 합성)
- **백엔드**: Node.js, Express 5, CORS, File-based JSON Database (`/data/records.json`)
- **반응형**: 스마트폰(iOS/Android), 태블릿(iPad 등), 데스크톱 완벽 지원

## 🚀 5. 실행 방법

### 로컬 개발 및 실행

```bash
# 1. 의존성 설치
npm install

# 2. 백엔드 서버 + 프론트엔드 동시 실행
npm run dev:all

# 3. 브라우저에서 접속
# 프론트엔드 개발 서버: http://localhost:5173
# 백엔드 API & 서빙: http://localhost:3001
```

### 프로덕션 빌드 및 단일 포트 실행

```bash
# 빌드
npm run build

# Express 서버 단일 실행 (dist 정적 파일 자동 서빙)
npm start
# http://localhost:3001 접속
```

## 🐙 6. GitHub CLI (`gh`) 연동 및 원격 저장소 배포 방법

이 프로젝트는 Git 저장소로 초기화되어 있으며, GitHub CLI를 통해 명령어 한 줄로 GitHub 원격 저장소를 생성하고 푸시할 수 있습니다.

```bash
# 1. GitHub CLI 로그인 (최초 1회)
gh auth login

# 2. GitHub에 새 저장소 생성 및 즉시 push
gh repo create mind-hotel-checkout --public --source=. --remote=origin --push

# 3. 완료 후 브라우저에서 확인
gh repo view --web
```
